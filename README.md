# ⛅ Weather App

A sleek and responsive weather forecast application built with **React.js** and **Tailwind CSS**. Users can enter any city or country to fetch real-time weather data using the OpenWeather API.

## 🔥 Features

- 🌍 Search by city or country
- ☀️ Real-time weather info (temperature, humidity, wind)
- 🌗 Clean, modern UI using Tailwind CSS
- 📱 Fully responsive design

## 🛠️ Tech Stack

- React.js
- Tailwind CSS
- OpenWeather API
